# 모바일 입력 흐름 점검 (2026-11-14)

기준: 운영 main7297002 및 사용자 iPhone 화면 녹화. 운영 원본에 테스트 판매를 생성하지 않는다.

| 구간 | 확인·수정 |
|---|---|
| 고객명·가입구분 | 필수 정보 없으면 저장 차단, 가입구분 변경은 동일 실제 요금제의 기존 구간 계산 사용 |
| 고객유형 | 같은 유형 재선택으로 요금제가 지워지는 문제 수정; 다른 유형 변경 시 해당 유형 요금제 재선택 |
| 요금제 | 네이티브 select blur 후 안내; 빈 선택은 유형 유지하고 저장 차단 |
| 안내 | 선택/닫기/Escape 후 안전한 버튼으로 복귀; 수동 재열기 지원, 약속 선택 보존 |
| VAS·번들 | 기존 보험/부가 약속 선택과 번들 모드 유지; 수수료·점수 변경 없음 |
| 저장·수정·삭제 | 기존 원자 저장과 중복 클릭 방지 유지; 실패 입력 유지/롤백/수정/삭제 회귀 재검증 |
| 모바일 | 320/390px 가로 넘침·필수 입력·포커스 회귀. 실제 iPhone picker 자체는 CI Chrome으로 재현할 수 없어 기기 확인 필요 |

진단: 녹화에서는 요금제 선택 후 안내 모달 종료 시 네이티브 요금제 목록이 다시 보인다. 기존 dialog.close의 브라우저 포커스 복원과 select를 그대로 열기 트리거로 쓰는 코드가 일치한다. 포커스를 select에 돌려주지 않는 경로로 바꾸되 선택 데이터와 안내 약속을 보존한다. 최종 테스트/배포 결과는 연결 PR 기록을 따른다.
